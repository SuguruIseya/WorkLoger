# 作業記録 PWA v0.2

## 今回の更新
- ダークモード系UI
- 出退勤欄をコンパクトな1行横並びに変更
- 月切り替えUIをカレンダー画面だけに限定
- カレンダー画面の不要な縦スクロールを抑制
- 時間ラベルタップで1時間（15分×4）を一括設定
- 15分マスは個別修正可能
- 「300円/h（仮定）」を追加
- 仮定込み合計と確定合計を併記
- 日単位の特別給を手入力可能
- IndexedDBへ移行。初回起動時に旧localStorageデータを自動移行
- JSONバックアップ / 復元を維持
- CSV出力に仮定・特別給情報を追加
- PWAアイコン / faviconを追加

## データ
作業記録はブラウザのIndexedDBに保存され、GitHub Pagesへ送信されません。
旧版のlocalStorageキー `worklog-data-v1` が存在する場合、初回起動時にIndexedDBへコピーします。

## GitHub Pages
このフォルダの中身をリポジトリへアップロードし、GitHub Pagesの配信元を `main / root` にします。


## v0.3 更新点
- カレンダーの月間合計のHTML構造を修正し、右寄せCSSが実際に適用されるように修正
- Service Workerのキャッシュ名を更新し、公開後に新しいCSS/HTMLへ切り替わりやすくした

## 更新方法
GitHub Pagesのリポジトリ内にあるアプリのファイルを、このZIP内のファイルで置き換えてください。`icons/` フォルダも含めて配置します。
既存の作業記録はIndexedDBに保存されるため、通常はファイル更新だけで消えません。ただし、更新作業前に設定画面からJSONバックアップを書き出しておくことをおすすめします。
iPhoneで古い表示が残る場合は、Safariでページを再読み込みしてください。ホーム画面から開いている場合は、いったんSafariでURLを開いて更新を確認してください。
