# 作業記録 PWA

Windows + ブラウザで開発し、iPhoneのSafariから利用する想定の個人用PWAです。

## 現在入っている機能

- 月間カレンダー
- 各日の報酬額表示
- 月間合計
- 日別の15分マス
- 10:00〜12:00 / 13:00〜15:00
- 300円/h、600円/h、0円/hの作業種別
- 作業種別の時給・名称変更
- 出勤・退勤時刻
- 作業内容＋着手時刻のログ
- ブラウザのlocalStorageへのローカル保存
- JSONバックアップ／復元
- CSV出力
- PWA用manifest / Service Worker

## Windowsでの試運転

このフォルダをVS Code等で開き、ローカルHTTPサーバーから配信してください。

Pythonが入っている場合は、ターミナルでこのフォルダに移動して、

    python -m http.server 8000

その後PCのブラウザで

    http://localhost:8000

を開きます。

## iPhoneから試す場合

PCとiPhoneを同じWi-Fiにつなぎ、PCのローカルIPアドレスを確認します。

例：

    http://192.168.1.20:8000

をiPhone Safariで開きます。

※ 実運用でPWAとして安定して使うなら、HTTPSで配信できるホスティングに置く方法を推奨します。

## 注意

これは第1版の土台です。

現在の保存先はlocalStorageです。実運用版ではIndexedDBへ移行し、データ量が増えても扱いやすくする予定です。

また、作業ログと15分マスの紐付けルールなどは今後仕様を詰める余地があります。
